# Contribuer

Merci de votre intérêt !

1. Ouvrez d'abord une issue pour décrire le problème ou l'amélioration.
2. Forkez le dépôt, créez une branche, ajoutez des tests.
3. Vérifiez que les tests passent (voir le README, section « Tests » ou « Développement »).
4. Ouvrez une pull request en français ou en anglais.

Le SDK reste **sans dépendance à l'exécution** : merci de ne pas en ajouter.
